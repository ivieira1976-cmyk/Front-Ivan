# AgendaPro Beauty — versão ajustada

Projeto reconstruído para reproduzir o layout da imagem de referência, com:

- cabeçalho responsivo e menu mobile;
- hero com imagem e cartões flutuantes;
- serviços com pesquisa em tempo real;
- categorias, profissionais e indicadores;
- modo escuro, rolagem suave e botão de voltar ao topo;
- HTML, CSS e JavaScript organizados por pastas.

## Estrutura

```text
AgendaPro_Beauty_Ajustado/
├── index.html
├── css/
│   ├── variables.css
│   ├── style.css
│   └── responsive.css
├── js/
│   └── main.js
└── img/
    └── imagens do layout
```

## Como executar

Abra `index.html` no navegador. Para desenvolvimento, também é possível usar a extensão **Live Server** do VS Code.

## Observação

As imagens incluídas foram preparadas a partir da referência fornecida para permitir que o projeto abra com o visual completo. Substitua-as por imagens próprias antes de publicar comercialmente.
